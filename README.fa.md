# Cloudict

> تایپ صوتی رایگان و متن‌باز برای **ویندوز، لینوکس و مک‌او‌اس**، بر پایهٔ **تشخیص گفتار گوگل**
> (از طریق وب‌سایت گوگل ترنسلیت) — تا بتوانید در *هر* برنامه‌ای، **رایگان** و به **بسیاری از
> زبان‌های دنیا** با صدای خود تایپ کنید، همراه با سیستم دستورات صوتی و رابط کاربری دوزبانه
> (انگلیسی / فارسی).

## این برنامه چه می‌کند

Cloudict گفتار شما را به متن تبدیل می‌کند و مستقیماً در برنامه‌ای که فوکوس دارد تایپ می‌کند —
ویرایشگر، مرورگر، چت، Word، هرجا. آن را مثل **تایپ صوتی گوگل (شبیه Gboard اندروید) ولی برای هر
برنامهٔ دسکتاپ** در نظر بگیرید: از **تشخیص گفتار گوگل — از دقیق‌ترین‌های موجود و کاملاً رایگان** —
با خودکارسازی صفحهٔ **گوگل ترنسلیت** در یک نشست کروم استفاده می‌کند. بدون API پولی، بدون حساب
کاربری و بدون مدل محلی.

سیستم **دستورات صوتی** هم دارد: با گفتن یک کلمه، علائم نگارشی درج کنید، کلید بفرستید (Enter، Tab و…)،
زبان صفحه‌کلید را عوض کنید یا برنامه‌ای را اجرا کنید.

> ℹ️ **نحوهٔ کار تشخیص گفتار (و نکتهٔ آن):** تشخیص بر پایهٔ رابط عمومی وب گوگل ترنسلیت است که با
> Selenium کنترل می‌شود. رایگان است و کلید API نمی‌خواهد، ولی اگر گوگل آن صفحه را تغییر دهد ممکن
> است از کار بیفتد. سلکتورها در *تنظیمات ← تنظیمات گوگل ترنسلیت* قابل ویرایش‌اند. مهاجرت به یک موتور
> اختصاصی (مثل Whisper) در نقشهٔ راه است.

## امکانات

- 🎙️ **تایپ در هر جا** — متن تشخیص‌داده‌شده در پنجرهٔ فعال تایپ می‌شود.
- 🖥️ **ویندوز، لینوکس و مک** — یک برنامه، یک رابط کاربری، سه سیستم‌عامل.
- 🌍 **تایپ به زبان‌های متعدد** — بیش از ۲۰ زبان (انگلیسی، فارسی، عربی، فرانسوی، آلمانی، اسپانیایی،
  روسی، هندی، چینی و…).
- 🌐 **رابط دوزبانه** — پیش‌فرض انگلیسی، فارسی قابل انتخاب، با پشتیبانی کامل راست‌به‌چپ.
- ⌨️ **میانبرهای سراسری** — `Ctrl+Alt+A` برای شروع/توقف و `Ctrl+Alt+S` برای توقف (قابل تغییر).
- 🗣️ **دستورات صوتی** — علائم نگارشی، کلیدهای خاص، تغییر زبان صفحه‌کلید، اجرای برنامه.
- 🛠️ **قابل تنظیم** — تأخیرهای انتقال متن و سلکتورهای گوگل ترنسلیت از داخل تنظیمات.
- 🔌 **اجرای آفلاین از همان اولین بار** — درایور متناسب مرورگر داخل همهٔ بسته‌ها هست.

## پیش‌نیازها

- **گوگل کروم.** Cloudict یک پنجرهٔ کروم را به‌عنوان مرورگر کمکی کنترل می‌کند. دقیقاً «کروم»:
  نسخه‌های کرومیوم بدون کلیدهای API گوگل ساخته می‌شوند و تشخیص گفتاری که گوگل ترنسلیت به آن متکی
  است، در آن‌ها بی‌سروصدا کار نمی‌کند.
- ویندوز ۱۰/۱۱ (۶۴ بیتی)، یک توزیع به‌روز لینوکس (۶۴ بیتی)، یا مک‌او‌اس ۱۱ به بالا (اپل سیلیکون یا اینتل).

باقی موارد همراه برنامه هستند. Cloudict خوداتکا است و نیازی به نصب .NET ندارد.

## نصب

بستهٔ سیستم خود را از صفحهٔ [Releases](../../releases) دانلود کنید.

### ویندوز

فایل **`Cloudict-x.y.z-Setup.exe`** را اجرا کنید.

از این نسخه، Cloudict برای اجرا نیازی به دسترسی مدیر ندارد. تنها کاری که بدون آن ممکن نیست، تایپ در
پنجره‌ای است که *خودش* با دسترسی مدیر اجرا شده — ویندوز ورودی مصنوعی را از سطح دسترسی پایین‌تر
نمی‌پذیرد. اگر به آن نیاز دارید، Cloudict را با «Run as administrator» اجرا کنید.

### لینوکس

<div dir="ltr">

```bash
sudo apt install ./cloudict_x.y.z_amd64.deb      # Debian, Ubuntu, Mint
sudo dnf install ./cloudict-x.y.z-1.x86_64.rpm   # Fedora, RHEL, openSUSE
chmod +x Cloudict-x.y.z-x86_64.AppImage && ./Cloudict-x.y.z-x86_64.AppImage   # بقیهٔ توزیع‌ها
```

</div>

**روی نشست‌های X11 هیچ تنظیم اضافه‌ای لازم نیست.**

**روی Wayland یک قدم اضافه لازم است.** Wayland عمداً به هیچ برنامه‌ای اجازهٔ تایپ در برنامهٔ دیگر
را نمی‌دهد، پس Cloudict از `ydotool` استفاده می‌کند که از طریق دستگاه ورودی مجازی کرنل کار می‌کند:

<div dir="ltr">

```bash
sudo apt install ydotool
systemctl --user enable --now ydotool
```

</div>

روی Wayland هیچ برنامه‌ای نمی‌تواند میانبر سراسری بگیرد. به‌جایش در تنظیمات صفحه‌کلید محیط دسکتاپ
خود میانبری تعریف کنید که این دستور را اجرا کند:

<div dir="ltr">

```
cloudict --toggle
```

</div>

مطمئن نیستید سیستم شما چه چیزی را پشتیبانی می‌کند؟ دستور `cloudict --diagnose` را اجرا کنید؛ دقیقاً
هرچه تشخیص داده شده را چاپ می‌کند.

### مک‌او‌اس

فایل `.dmg` را باز کنید و Cloudict را در Applications بیندازید. برای اپل سیلیکون نسخهٔ **arm64** و
برای اینتل نسخهٔ **x64** را بردارید.

این نسخه **توسط اپل امضا نشده** (امضا نیازمند عضویت پولی در برنامهٔ توسعه‌دهندگان است)، پس Gatekeeper
بار اول جلوی اجرا را می‌گیرد. یا روی برنامه راست‌کلیک کنید و **Open** را بزنید، یا:

<div dir="ltr">

```bash
xattr -dr com.apple.quarantine /Applications/Cloudict.app
```

</div>

سپس مک بار اولی که Cloudict بخواهد تایپ کند، دسترسی **Accessibility** می‌خواهد. آن را از مسیر
*System Settings ← Privacy & Security ← Accessibility* فعال کنید؛ بدون آن، مک تمام کلیدهایی که
Cloudict می‌فرستد را بی‌صدا دور می‌ریزد.

## نحوهٔ استفاده

۱. Cloudict را اجرا کنید.
۲. روی **باز کردن مرورگر کمکی** بزنید تا گوگل ترنسلیت باز شود، سپس دکمهٔ سبز (یا `Ctrl+Alt+A`) را
   برای شروع شنیدن بزنید.
۳. صحبت کنید — کلمات شما در برنامه‌ای که فوکوس دارد تایپ می‌شوند.
۴. تأخیرها، میانبرها و دستورات صوتی را در **تنظیمات** مدیریت کنید.

می‌خواهید متن به‌جای تایپ در برنامهٔ دیگر، داخل خود Cloudict جمع شود؟ گزینهٔ **انتقال به مکان نشانگر
تایپ** را خاموش بگذارید تا کلمات در کادر *متن نهایی* جمع شوند.

### خط فرمان

<div dir="ltr">

| دستور | کار |
|---|---|
| `cloudict --toggle` | شروع یا توقف تایپ صوتی در نمونهٔ در حال اجرا |
| `cloudict --start` / `--stop` | شروع یا توقف صریح |
| `cloudict --diagnose` | چاپ قابلیت‌های این سیستم و محل کروم و درایور |
| `cloudict --version` | چاپ نسخه |

</div>

### تغییر زبان

از **تنظیمات ← تنظیمات عمومی ← زبان رابط کاربری**، انگلیسی یا فارسی را انتخاب کنید، ذخیره کنید و
برنامه را دوباره اجرا کنید. زبان پیش‌فرض و جایگزینِ متن‌های ترجمه‌نشده، انگلیسی است.

## نکته‌هایی برای بهترین نتیجه

- **پنجرهٔ مرورگرِ کمکی را مینیمایز نکنید.** آن را باز نگه دارید؛ می‌توانید پنجره‌های دیگر را **روی**
  آن قرار دهید، اما مینیمایز کردن، تشخیص گفتار را متوقف می‌کند.
- **تأخیرها را با سیستم خود هماهنگ کنید.** Cloudict *از طریقِ* صفحهٔ زندهٔ گوگل ترنسلیت کار می‌کند و
  آن صفحه هنگام صحبت مدام کلمات را اصلاح می‌کند، پس چند تأخیر زمانی این دو را هماهنگ نگه می‌دارند.
  مقادیر پیش‌فرض برای بیشتر کاربران مناسب‌اند؛ در صورت نیاز در **تنظیمات ← تأخیرهای انتقال متن**
  تنظیمشان کنید.

## دربارهٔ درایور مرورگرِ همراه برنامه

Cloudict از طریق **ChromeDriver** با کروم صحبت می‌کند و نسخهٔ اصلی درایور باید با نسخهٔ اصلی کروم شما
یکی باشد. **همهٔ بسته‌ها یکی از آن را همراه دارند**، پس برنامه بلافاصله پس از نصب کار می‌کند — بدون
دانلود، بدون انتظار و حتی بدون اتصال به اینترنت.

کروم خودش را به‌روز می‌کند، پس دیر یا زود از درایور همراه جلو می‌افتد. Cloudict این را خودش مدیریت می‌کند:

۱. **هر درایور جدیدترِ سازگاری که از قبل روی سیستم شماست، اولویت دارد.** Cloudict پوشهٔ خودش، حافظهٔ
   دانلودش، مسیرهای سیستمی درایور، حافظهٔ Selenium و مسیرهای `PATH` را بررسی می‌کند و جدیدترین درایورِ
   سازگار با کروم شما را برمی‌دارد. درایوری که از قبل داشته‌اید هرگز با درایور همراه ما بازنویسی یا
   قدیمی‌تر نمی‌شود.
۲. **اگر کروم شما از همهٔ درایورهای موجود جلوتر باشد**، فقط *یک‌بار* درایور متناسب در پوشهٔ دادهٔ
   کاربر دریافت می‌شود — هرگز در پوشهٔ نصب. ابتدا میرورها امتحان می‌شوند و بعد میزبان خود گوگل که از
   برخی کشورها در دسترس نیست.
۳. **اگر آن دانلود هم ممکن نباشد** (آفلاین یا مسدود)، Cloudict به‌جای اجرا نشدن، از نزدیک‌ترین درایوری
   که دارد استفاده می‌کند.

پس تنها چیزی که همیشه لازم دارید، خودِ کروم است.

## ساخت از منبع

نیازمند [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

<div dir="ltr">

```bash
git clone https://github.com/farshad-zamani/cloudict.git
cd cloudict

dotnet run --project src/Cloudict.App          # اجرا
dotnet test src/Cloudict.Core.Tests            # تست‌ها
```

</div>

### ساخت بسته‌ها

<div dir="ltr">

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-all.ps1
```

</div>

هر بسته به ابزاری نیاز دارد که فقط روی سیستم‌عامل خودش وجود دارد — Inno Setup برای اینستالر ویندوز،
`dpkg`/`rpmbuild` برای بسته‌های لینوکس و ابزارهای مخصوص مک برای باندل `.app` — پس یک ماشین به‌ندرت
می‌تواند همهٔ آن‌ها را بسازد. [ورک‌فلوی ریلیز](.github/workflows/release.yml) کل مجموعه را با یک
رانر برای هر پلتفرم می‌سازد.

## ساختار پروژه

<div dir="ltr">

```
src/
├─ Cloudict.Core/       منطق برنامه — بدون UI و بدون تماس سیستم‌عامل
├─ Cloudict.Platform/   تمام تماس‌های سیستم‌عامل، پشت اینترفیس، انتخاب در زمان اجرا
├─ Cloudict.App/        رابط کاربری Avalonia
└─ Cloudict.Core.Tests/ تست‌های Core
packaging/              windows · linux · macos
```

</div>

پروژهٔ Core به‌تنهایی و بدون هیچ فریم‌ورک رابط کاربری کامپایل می‌شود — همین است که نمی‌گذارد فرضیات
مخصوص یک پلتفرم دوباره و بی‌سروصدا وارد کد شوند. جزئیات در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
