## English

Cloudict 3.2.9 improves continuous dictation and voice shortcuts.

- **Recover from a dropped microphone:** Cloudict watches Google Translate's own listening state,
  preserves and transfers the unsent text once, and attempts to restart recognition before stopping.
- **Release capture on Stop:** microphone access is released for the helper page even if its
  microphone button is already off. Start restores access. Stopping retains the source text.
- **Cleaner phrase starts:** invisible direction marks and zero-width editor placeholders no
  longer introduce a leading space; ordinary word spacing and Persian joiners are preserved.
- **Choose multi-key voice shortcuts:** select a main key and any combination of Ctrl, Alt, Shift
  and Win / Cmd, including `Ctrl+Alt+S`. This avoids pressing an active global shortcut to define it.
- **New bilingual screenshot guides:** actual English and Persian UI captures show voice commands,
  text snippets, available actions, language selection and settings. Settings offers 18 dictation
  languages; the interface is English or Persian.

**Voice Stop example:** add “stop typing” → Send key → S → tick Ctrl and Alt → save the command
and Settings. Speak the phrase while listening. Use your configured Stop shortcut if it differs
from the default. Use Start to listen again afterwards.

214 automated tests passed locally, with additional Windows UI, native key-injection and live
Google Translate browser checks. These checks reproduce the failure paths; they do not establish
that every intermittent network, device or editor issue has disappeared during hours of use.

## فارسی

نسخهٔ ۳.۲.۹ پایداری تایپ صوتی و تعریف میان‌برهای صوتی را بهبود می‌دهد.

- **بازیابی میکروفون قطع‌شده:** وضعیت خودِ گوگل ترنسلیت بررسی می‌شود؛ متن باقی‌مانده یک‌بار
  منتقل می‌شود و پیش از توقف کامل، راه‌اندازی مجدد امتحان می‌شود.
- **آزادشدن ضبط هنگام توقف:** دسترسی میکروفونِ صفحهٔ کمکی، حتی اگر دکمهٔ سایت خاموش باشد،
  آزاد می‌شود و با شروع دوباره برمی‌گردد. توقف، متن داخل سایت را نگه می‌دارد.
- **اصلاح فاصلهٔ ابتدای عبارت:** علائم نامرئی جهت متن و نویسه‌های بدون عرضِ ویرایشگر باعث درج
  فاصلهٔ اضافه نمی‌شوند؛ فاصله‌گذاری عادی و نیم‌فاصلهٔ فارسی حفظ شده‌اند.
- **تعریف دستور صوتی چندکلیدی:** کلید اصلی و هر ترکیبی از Ctrl، Alt، Shift و Win / Cmd را
  جدا انتخاب کنید؛ از جمله `Ctrl+Alt+S`، بدون نیاز به فشردن میان‌بر فعال هنگام تعریف آن.
- **معرفی تصویری دوزبانه:** تصاویر واقعی فارسی و انگلیسی، دستورات صوتی، متن آماده، انواع عملیات،
  انتخاب زبان و تنظیمات را نشان می‌دهند. ۱۸ زبان دیکته قابل انتخاب است؛ رابط برنامه فارسی یا انگلیسی است.

**نمونهٔ توقف با صدا:** «توقف تایپ» ← ارسال کلید ← S ← تیک Ctrl و Alt ← ذخیرهٔ دستور و تنظیمات.
عبارت را هنگام فعال‌بودن دیکته بگویید. اگر میان‌بر توقف را تغییر داده‌اید، همان ترکیب را انتخاب کنید.
پس از توقف، با دکمه یا میان‌بر شروع، شنیدن را دوباره فعال کنید.

۲۱۴ آزمون خودکار محلی، همراه با بررسی رابط ویندوز، ارسال واقعی کلید و صفحهٔ واقعی گوگل ترنسلیت
موفق بوده‌اند. این بررسی‌ها مسیر خطا را بازتولید می‌کنند؛ رفع تمام حالت‌های پراکندهٔ شبکه، دستگاه و
ویرایشگر در استفادهٔ چندساعته را تضمین نمی‌کنند.
